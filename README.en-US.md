

# python_spider

#### Introduction
Web crawler learning. Practical examples: Weibo post and comment crawler, Vipshop product crawler, Kuaishou video downloader, Nanjing University of Information Science and Technology (NUIST) announcements, etc.


#### Usage Instructions

1.  This project is a practical learning project intended for educational purposes only. It is not to be used for commercial purposes.
2.  Some projects are not fully implemented and are for reference only.
3.  Currently implemented features include: Weibo post and comment crawler, Vipshop product crawler, Kuaishou video downloader, NUIST announcements, etc.
